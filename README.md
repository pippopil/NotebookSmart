# 📱 NotebookSmart — Умные заметки, расчет оплат и списки покупок

Мобильное кроссплатформенное приложение заметок с авто-подсчетом оплат, анализом списков покупок и подбором магазинов и маркетплейсов для быстрой покупки и доставки.

[![Build NotebookSmart Android & PWA](https://github.com/pippopil/NotebookSmart/actions/workflows/android-build.yml/badge.svg)](https://github.com/pippopil/NotebookSmart/actions/workflows/android-build.yml)

## 🚀 Основные возможности

1. **Умный калькулятор прямо в тексте заметок**:
   - Автоматическое вычисление сумм и выражений в реальном времени при вводе строк:
     - `Аренда: 35000 руб`
     - `Свет + вода: 2400 + 1350` -> `= 3 750 ₽`
     - `Обед в кафе: 450 * 2` -> `= 900 ₽`
     - `Скидка: 3000 - 15%` -> `= 2 550 ₽`
   - Подсчет общего итога по всем строкам оплаты и кнопка вставки «Итого» в текст.
   - Быстрая цифровая клавиатура операторов (`+`, `-`, `×`, `÷`, `%`, `₽`, `к`, `[ ] чекбокс`).

2. **Списки покупок и «Где купить»**:
   - Автоматический парсинг продуктов из текста заметок с определением фасовки (`Молоко 3.2% 2 л`, `Сыр 500 г`, `Хлеб`).
   - **Маркетплейсы**: быстрый поиск всей корзины на **Wildberries**, **Ozon Fresh**, **Яндекс Маркет**, **Мегамаркет**.
   - **Экспресс-доставка (15–30 минут)**: прямые переходы в **Купер (СберМаркет)**, **Самокат**, **Яндекс Лавку**, **ВкусВилл**, **Пятёрочку Доставку**.
   - **В самом магазине (офлайн)**: поиск ближайших сетевых супермаркетов на карте («Пятёрочка», «Магнит», «ВкусВилл», «Перекрёсток») с расчетом дистанции в метрах и переходом в **Яндекс Карты**, **2ГИС**, **Google Maps**.
   - **Режим «В магазине»**: тактильный чеклист для вычеркивания товаров пальцем в супермаркете с вибрацией и прогресс-баром.

3. **PWA и Android**:
   - Полная поддержка PWA (Progressive Web App): установка на рабочий стол Android / iOS.
   - Автономный офлайн-режим с локальным хранилищем.

4. **Синхронизация через Firebase**:
   - Синхронизация в реальном времени между смартфоном, планшетом и ПК.
   - Генерация QR-кода для мгновенного подключения мобильного устройства через сканирование камерой.

5. **GitHub Actions CI/CD**:
   - Автоматическая сборка Android APK и PWA артефактов через `.github/workflows/android-build.yml`.

## 🛠 Запуск и разработка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка проекта
npm run build
```
