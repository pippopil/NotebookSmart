# 📓 NotebookSmart — Умная тетрадь: Заметки, Финансы, Покупки и События

**NotebookSmart** — это интеллектуальное кроссплатформенное приложение в стиле классической тетради со спиралью, красными полями и клеткой 5 мм. Оно объединяет ультрабыстрый веб-интерфейс на **React 19, TypeScript и Tailwind CSS v4** с мощным нативным **Android-мостом («Усиленный гибрид»)**, системным виджетом рабочего стола, точным будильником `AlarmManager`, аппаратным виброоткликом, встроенным калькулятором прямо в тексте, графиками расходов Recharts, AI-автотегами на Gemini 3.8 Flash и защитой данных по PIN-коду и биометрии.

## ⚡ Архитектура «Усиленный гибрид» (Enhanced Hybrid)

Начиная с версии **1.9.5**, в приложении реализована передовая архитектура **«Усиленный гибрид»**:
- **Быстрота и гибкость веб-ядра**: Единая кодовая база на React 19 / TypeScript для Web, PWA и Android, позволяющая мгновенно обновлять интерфейс без долгой перекомпиляции.
- **Прямой нативный Java/Android мост (`AndroidNativeBridge.java` & `window.AndroidNative`)**: Без тяжелых сторонних зависимостей WebView напрямую взаимодействует с сервисами Android.
- **Нативный виджет рабочего стола (`RemoteViews` AppWidget)**:
  - Форматы 3x2 и 4x2 для домашнего экрана смартфона;
  - Показывает актуальный чеклист покупок (первые некупленные товары и счетчик оставшихся) либо суммарные расходы по счетам;
  - Данные сохраняются в `SharedPreferences` и обновляются автоматически при любом изменении заметок;
  - Клик по виджету мгновенно открывает приложение на нужном разделе.
- **Точные фоновые напоминания (`AlarmManager` + `BroadcastReceiver`)**:
  - Метод `setExactAndAllowWhileIdle` гарантирует срабатывание уведомления секунда в секунду;
  - Уведомления и вибрация приходят даже при закрытом/выгруженном приложении и в энергосберегающем режиме Android Doze;
  - Системный канал `notebook_reminders_channel` с высоким приоритетом.
- **Аппаратная виброотдача (Hardware Vibrator / Haptic Feedback)**:
  - Прямой вызов `VibrationEffect` с градацией силы отклика (`light`, `medium`, `heavy`, `success`, `warning`);
  - Автоматический бесшовный переход на Web Vibration API при работе в браузере.

## 🌟 Ключевые возможности

### 1. 📝 Тетрадь в клетку с живым авто-калькулятором
- Полноценные тетрадные листы с настоящими красными полями, перфорацией и металлическими кольцами спирали;
- 5 стилей бумаги: *Классическая клетка*, *В линейку*, *Крафтовая бумага*, *Точечная сетка (Bullet Journal)* и *Слоновая кость*;
- Дневной и ночной режимы («День» / «Ночь») с автосохранением темы;
- **Прямой расчет оплат в тексте**:
  - `Аренда квартиры: 35 000 руб`
  - `Коммуналка: 2400 + 1350` ➔ `= 3 750 ₽`
  - `Обед на двоих: 450 * 2` ➔ `= 900 ₽`
  - `Скидка: 3000 - 15%` ➔ `= 2 550 ₽`
  - Учет количеств в штуках: `Цемент: 5 шт * 380` ➔ `= 1 900 ₽ (5 шт.)`
- Разделение на **Прибыль (+) и Расходы (-)** с автоподсчетом чистого финансового остатка и нормы сбережений.

### 2. 📊 Графическая аналитика расходов (Recharts)
- **Гистограмма ежемесячных трат в Архиве**:
  - Хронологическая динамика расходов по закрытым периодам;
  - Сравнение с прошлым месяцем (+/- % и сумма экономии или перерасхода);
  - Индикаторы среднего уровня расходов, месяца минимальных и пиковых трат;
  - Переключение режимов «Только расходы» и сопоставительного «Расходы и Доходы».
- **Круговая диаграмма в разделе Финансов**:
  - Распределение затрат по категориям и смарт-тегам (`#shopping`, `#food`, `#work`, `#transport`, `#finances`).

### 3. 🛒 Умные покупки, корзина и поиск магазинов
- Автораспознавание продуктов и весовых категорий (`Молоко 3.2% 1 л`, `Сыр 300 г`, `Хлеб 1 шт`);
- **Расчет минимальной стоимости корзины** и вычисление общей экономии;
- **Память брендов**: приложение запоминает марки, которые вы чаще выбираете, и рекомендует их;
- **Многоуровневая геолокация**:
  - Каскад: Нативный GPS ➔ Браузерный GPS ➔ Геолокация по сети (IP) без запроса системных разрешений;
  - Точное расстояние и минуты ходьбы до ближайших супермаркетов («Пятёрочка», «Магнит», «ВкусВилл», «Перекрёсток»);
  - Построение маршрутов в Яндекс Картах, 2ГИС и Google Maps;
- Быстрый заказ и поиск корзины на маркетплейсах (**Wildberries**, **Ozon Fresh**, **Купер**, **Самокат**, **Яндекс Лавка**, **ВкусВилл**).

### 4. 🎙️ Голосовой ввод и OCR-сканер чеков
- **Web Speech API**: диктуйте текст заметок в режиме реального времени;
- Распознавание служебных голосовых команд («новая строка», «точка», «запятая», «рублей»);
- **OCR сканер**: моментальное распознавание рукописного текста, смет и чеков прямо с камеры смартфона или фото из галереи.

### 5. ✨ AI Авто-тегирование (Gemini 3.8 Flash)
- Автоматический семантический анализ заметок с помощью `@google/genai`;
- Определение тем (#urgent, #work, #personal, #shopping, #finances);
- Офлайн эвристический классификатор ключевых слов без задержек и интернета;
- Быстрая фильтрация заметок по клику на тег.

### 6. 🛡️ Безопасность: PIN-код и биометрия
- 4-значный PIN-код с криптографическим хэшированием SHA-256 и солью;
- Биометрический вход через WebAuthn: **Touch ID**, **Face ID**, сканер отпечатка пальца на Android;
- Выборочная защита конфиденциальных вкладок («Финансы», «Покупки», «Архив»);
- Сокрытие приватных расчетов на карточках заметок до ввода пароля.

### 7. 🛡️ Гарантированное сохранение данных
- Трёхуровневое хранилище: **LocalStorage + Safe Backup + IndexedDB**;
- Автоматическое фоновое дублирование и восстановление при случайной очистке кэша;
- Активация Persistent Storage API в Android WebView и мобильных браузерах;
- Экспорт и импорт полной резервной копии базы заметок в JSON.

### 8. ☁️ Синхронизация между устройствами
- Обмен заметками в реальном времени через **Firebase Firestore** по коду комнаты (Room ID);
- Мгновенное подключение второго устройства по сканированию QR-кода камерой телефона.

## 📲 Установка приложения

### 🟢 1. На Android (Смартфоны и планшеты)

#### Вариант А: Установка готового APK файла с виджетом рабочего стола (Рекомендуемый)
1. Перейдите в раздел **[GitHub Releases](https://github.com/pippopil/NotebookSmart/releases/latest)**.
2. Скачайте свежий файл **`NotebookSmart-v1.9.5.apk`**.
3. Установите APK на смартфон.
4. Вы получите все возможности **«Усиленного гибрида»**: нативный виджет рабочего стола, точные будильники `AlarmManager` и системную виброотдачу.
5. Для добавления виджета: зажмите палец на пустом месте экрана телефона ➔ выберите **«Виджеты»** ➔ найдите **«NotebookSmart»** ➔ перетащите на рабочий стол.

#### Вариант Б: PWA установка через браузер
1. Откройте приложение в **Chrome**, **Яндекс Браузере** или **Samsung Internet**.
2. Нажмите кнопку **«Установить»** в шапке или выберите в меню браузера **«Добавить на главный экран»**.

---

### 🍎 2. На iPhone и iPad (iOS Safari)
1. Откройте приложение в браузере **Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх в нижней панели).
3. Выберите пункт **«На экран "Домой"»** (Add to Home Screen) и подтвердите добавление.
4. Приложение запустится в полноэкранном нативном режиме без рамок браузера.

---

### 💻 3. На компьютер (Windows, macOS, Linux)
1. Откройте приложение в **Google Chrome**, **Microsoft Edge** или **Яндекс Браузере**.
2. В правой части адресной строки нажмите значок **«Установить NotebookSmart»**.
3. Приложение установится как независимая настольная программа с ярлыком на рабочем столе.

## 🛠️ Стек технологий

- **Фронтенд**: React 19, TypeScript, Tailwind CSS v4, Motion (Framer Motion), Lucide React.
- **Графика и чарты**: Recharts (гистограммы и круговые диаграммы).
- **Сборщик**: Vite 8, `vite-plugin-pwa`, Workbox.
- **Серверная часть**: Node.js, Express, TSX.
- **Искусственный интеллект**: Google Gemini 3.8 Flash (`@google/genai`).
- **Мобильный стек**: Android SDK (Java 21), Capacitor 8, AppWidget RemoteViews, Android AlarmManager, NotificationManager.
- **База данных**: IndexedDB (Dexie/idb pattern), LocalStorage, Firebase Firestore.
- **Безопасность**: WebAuthn API (Face ID / Touch ID), SubtleCrypto SHA-256.

## 💻 Локальная разработка и сборка

```bash
# 1. Клонирование репозитория
git clone https://github.com/pippopil/NotebookSmart.git
cd NotebookSmart

# 2. Установка зависимостей
npm install

# 3. Запуск сервера разработки (порт 3000)
npm run dev

# 4. Проверка типов TypeScript
npm run lint

# 5. Сборка производственного PWA бандла
npm run build

# 6. Сборка Android APK (требуется Android SDK или запуск через GitHub Actions)
cd android
./gradlew assembleDebug
```
